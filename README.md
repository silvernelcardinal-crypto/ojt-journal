## 🔁 How I keep this updated

1. Edit `data/ojt.js` in my portfolio repo — that is the one source of truth.
2. Run `Update-Journal.bat` — this regenerates every file in `days/`.
3. Commit and push the day's entry:

```bash
cd ../ojt-journal
git add .
git commit -m "Day 1: orientation and team setup"
git push
```
